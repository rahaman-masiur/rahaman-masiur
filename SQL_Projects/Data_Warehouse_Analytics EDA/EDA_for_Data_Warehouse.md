
# SQL Data Exploration — EDA Project

A MySQL-based exploratory data analysis (EDA) on a star-schema sales data warehouse. The project inspects customers, products, sales transactions, dates, and magnitudes to surface business insights.

---

## Data Model

| Table | Type | Records | Description |
|-------|------|---------|-------------|
| `dim_customers` | Dimension | ~18,500 | Customer demographics (country, gender, marital status, age) |
| `dim_products` | Dimension | ~300 | Product catalog (category, subcategory, product line, cost) |
| `fact_sales` | Fact | ~60,400 | Sales transactions (date, quantity, sales amount, price) |

Schema: `datawarehouseanalytics`

---

## EDA Structure

| SQL File | Focus Area |
|----------|------------|
| `data_exploration.sql` | Database schema inspection, column profiles, top-N record previews |
| `Dimension_exploration.sql` | Categorical breakdowns: country, gender, marital status, product categories |
| `Date_exploration.sql` | Date range, customer age demographics, yearly & quarterly order trends |
| `Measure_exploration.sql` | Revenue totals, item counts, average selling price, order frequency |
| `Magnitude_analysis.sql` | Sales by geography, quantity by category, per-customer revenue & order counts |

---

## Key Questions & Insights

### 1. Database Overview
- Schema contains **3 tables**: `dim_customers`, `dim_products`, `fact_sales`
- Initial record previews confirm data types and completeness across dimensions and facts

### 2. Dimension Breakdowns
- **Customer distribution**: Country-wise customer concentration, gender split, and marital status composition
- **Product catalog**: ~300 products across **Bikes**, **Components**, **Clothing**, and **Accessories** with subcategory and product-line granularity
- No nulls found in `category` or `subcategory` fields

### 3. Date & Demographics
- **Sales span**: multi-year transaction history with month-level and year-level range calculated
- **Customer age range**: youngest and oldest customers identified overall and by gender
- **Order trends**: total orders per year and per quarter to spot seasonality and growth patterns

### 4. Revenue & Volume Measures
- **Total revenue** computed from all sales transactions
- **Distinct items sold** identified across the product catalog
- **Revenue by category** with grand total appended
- **Order frequency per product** to find top-selling SKUs
- **Total customer base** quantified from the dimension table

### 5. Magnitude Analysis
- **Sales by country**: geographic revenue concentration
- **Quantity by category**: volume sold aggregated and unioned with a total row
- **Per-product metrics**: total quantity, total revenue, and average price per product
- **Customer engagement**: count of customers who actually placed orders vs. total registered customers
- **Per-customer value**: total orders placed and revenue generated by each customer

## Tech Stack

- **MySQL** — data warehouse and querying engine
- **CSV exports** — `gold.dim_customers.csv`, `gold.dim_products.csv`, `gold.fact_sales.csv` (reference data)

---

## How to Run

1. Import the CSV files into a MySQL database named `datawarehouseanalytics`.
2. Run the SQL scripts in any order, or sequentially by the numbered logic above.
3. All scripts use standard SQL compatible with MySQL 8.x+.
